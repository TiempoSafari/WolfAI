# 🐺 网页版单人狼人杀（AI玩家）需求文档（增强版）

## 1. 项目概述

### 1.1 项目背景

狼人杀是一款经典的社交推理游戏，但传统玩法需要6-12人同时在线，组织难度大。本项目旨在打造一款**单人可玩的网页版狼人杀**，其他玩家均由LLM（大语言模型）智能体扮演，实现随时随地的完整游戏体验。系统支持**云端API调用**与**本地LLM部署**双模式，兼顾易用性与隐私性。

### 1.2 项目目标

| 目标类型 | 描述 |
| ------ |------ |
| 核心目标 | 实现1人+AI的完整狼人杀对局体验，支持云端与本地LLM双模式 |
| 体验目标 | AI玩家表现接近真人，具有个性、策略和"生命力" |
| 技术目标 | 基于多智能体架构，支持LLM双路径调用、状态管理与实时交互 |
| 隐私目标 | 本地模式下用户数据不出内网，保障隐私安全 |
| 商业目标 | 可拓展为付费产品或技术展示案例，支持SaaS与私有化部署 |

### 1.3 目标用户

- **狼人杀爱好者**：无法凑齐真人玩家时的替代方案
- **AI技术爱好者**：观察LLM博弈行为与推理能力
- **推理游戏玩家**：享受逻辑对抗的乐趣
- **新手训练者**：练习发言、逻辑与心态
- **隐私敏感用户**：希望数据本地化处理的玩家

### 2.2 游戏模式

| 模式 | 人数 | 角色配置 | 预计时长 |

| 快速局 | 6人 | 2狼+2民+预言家+女巫 | 10-15分钟 |

| 完整局 | 12人 | 4狼+4民+预言家+女巫+猎人+守卫 | 20-30分钟 |

### 2.3 角色系统

#### 2.3.1 好人阵营

| 角色 | 数量 | 技能 | 胜利条件 |
| ------ |------ |------ |------ |
| 平民 | 可变 | 无特殊技能 | 放逐所有狼人 |
| 预言家 | 1 | 每晚查验1人身份 | 同上 |
| 女巫 | 1 | 解药(救人)+毒药(杀人)，不能同晚使用 | 同上 |
| 猎人 | 1 | 死亡时可开枪带走1人 | 同上 |
| 守卫 | 1(可选) | 每晚守护1人免死，不能连续守同一人 | 同上 |
| 白痴 | 1(可选) | 被投票放逐时可翻牌免死 | 同上 |

#### 2.3.2 狼人阵营

| 角色 | 数量 | 技能 | 胜利条件 |
| ------ |------ |------ |------ |
| 普通狼人 | 可变 | 每晚共同选择杀1人 | 屠边(杀光神职或村民) |
| 狼王 | 1(可选) | 死亡时可开枪带走1人 | 同上 |
| 白狼王 | 1(可选) | 白天可自爆带走1人 | 同上 |

### 3.3 LLM调用双模式设计

#### 3.3.1 云端API模式

- **适用场景**：快速体验、高性能需求、无本地算力
- **支持模型**：
  - 通义千问（Qwen-Max, Qwen-Turbo）
  - OpenAI GPT-4 / GPT-3.5
  - Anthropic Claude
- **功能特性**：
  - API密钥管理界面
  - 自动重试与降级策略
  - 用量统计与费用预估
  - 响应缓存以降低成本

#### 3.3.2 本地LLM模式

- **适用场景**：隐私优先、离线使用、技术爱好者
- **支持部署方式**：
  - Ollama（推荐，支持Llama3、Qwen等）
  - LM Studio（Windows友好）
  - vLLM（高性能推理）
- **功能特性**：
  - 本地模型自动发现
  - 模型加载状态监控
  - 性能自适应（根据响应时间调整AI思考深度）
  - 支持GGUF、Safetensors等格式

#### 3.3.3 调用抽象层设计

```python
class LLMProvider:
    def __init__(self, mode: str = "cloud"):
        self.mode = mode  # "cloud" or "local"
        self.client = self._init_client()

    def _init_client(self):
        if self.mode == "cloud":
            return CloudLLMClient(api_key=os.getenv("LLM_API_KEY"))
        else:
            return LocalLLMClient(base_url="http://localhost:11434")

    def generate(self, prompt: str, **kwargs) -> str:
        return self.client.generate(prompt, **kwargs)

    def switch_mode(self, new_mode: str):
        self.mode = new_mode
        self.client = self._init_client()
```

## 5. 部署与运维

### 5.1 部署方案

| 方案 | 说明 |
| ------ |------ |
| **SaaS部署** | 前端+后端+云端LLM，适合大众用户 |
| **本地部署** | 支持Docker一键部署，含本地LLM支持 |
| **混合模式** | 前端网页 + 本地LLM + 远程游戏引擎 |

### 5.2 性能优化

- **AI响应缓存**：对常见场景预生成回复
- **异步处理**：AI思考过程异步执行，避免阻塞
- **负载均衡**：多LLM提供者自动切换

### 5.3 安全与隐私

- 云端模式：数据加密传输，API密钥安全存储
- 本地模式：数据不出内网，完全私有化
- 用户可选择数据是否用于模型优化
